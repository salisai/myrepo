Git: 
=====
- Distributed version control system(VCS).
- for software maintenance 
- VCS track changes between different software versions. 
- backup and restore. 
- collaboration 
- Branching and merging 
- Tracking changes, by whom? 



- configure git with username and email 
- git config --global user.name "Paul"
- git config --global user.email sayedalishah@..

- git config --list 
- ls -la    - show the .git folder 


Staging area: 
-------------
When you added the files and are ready for commits - it is in staging area. 
You have to commit after this. 
Between commit and local stage. 

git commit: 
- captures a snapshot of the project's currently staged changes, 
  creating a permanent record in the repository's history. 

Image: See git workflow in the git-workflow.png. 

Why staging: 
- its preparation phase 
- extra precaution 

- git log   - to check is it commited. 
- git diff  - different betweeen present and previous code.
